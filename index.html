Principle 1 • Reasoning Engines (o3 / DeepSeek)

Never Add "Think Step-by-Step"

OpenAI o3 and DeepSeek R1 run hidden latent chain-of-thought tokens. Forcing explicit CoT degrades search branches, consumes user output tokens redundantly, and can induce circular loops.

Principle 2 • Omni Multimodal (GPT-4o & Gemini)

Demand Structured XML & Visual Directives

GPT-4o and Gemini 2.5 Pro excel with explicit shot breakdowns, camera lens cues (e.g. anamorphic, chiaroscuro), timecodes, and clear delimiters (<previous_scene>, <extension_goal>).

Principle 3 • Autonomous Agents (Manus / Base44)

Enforce State Gates & Anti-Placeholder Rules

Autonomous runtime agents require definitive stop assertions, tool output checks, and zero-tolerance directives against truncated boilerplate like "// insert rest of code".
